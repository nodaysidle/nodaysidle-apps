02 / BEFORE YOU INSTALL

Plain facts.
No surprises.

Which platforms?

Desktop releases ship for macOS Apple Silicon and/or Linux x86_64 only — no Windows and no Intel Mac builds. WhisperBar is Apple Silicon only; the browser is Linux only. nodaysrammar is a Chromium MV3 extension (Chrome, Brave, Edge); sideload from the zip, not the Chrome Web Store.

macOS Gatekeeper

macOS apps are ad-hoc signed, not notarized. On first launch, right-click the app and choose Open. If needed, use System Settings → Privacy & Security → Open Anyway.

Linux AppImages

Run chmod +x on the AppImage before launching. NODAYSIDLE Browser also needs system GTK 3 and WebKitGTK 4.1.

Checksums

SHA-256 values come from the GitHub release notes, README, or asset digest. Never invent a hash. Verify with shasum -a 256 or sha256sum.
